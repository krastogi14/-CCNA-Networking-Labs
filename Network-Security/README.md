# Network Security Labs

## Overview

This folder contains Cisco Packet Tracer labs demonstrating fundamental network security concepts used to control and protect network communication. The lab focuses on Access Control Lists (ACLs), which are used to filter network traffic according to defined security rules.

---

## Objectives

- Understand the purpose of Access Control Lists (ACLs).
- Configure ACL rules on Cisco routers.
- Control network traffic using permit and deny statements.
- Apply ACLs to appropriate router interfaces.
- Verify ACL configuration and traffic filtering.
- Test network connectivity after applying security policies.
